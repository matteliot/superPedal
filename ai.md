### Implementation decisions: superPedal (requirement 4)

- **Toolchain (as every pedal).** `no_std` Rust, edition 2024, nightly (`rust-toolchain.toml` with `thumbv7em-none-eabihf` and `llvm-tools`), `.cargo/config.toml` (default target `thumbv7em-none-eabihf`, rustflags `-C target-cpu=cortex-m7 -C target-feature=-fp64`, alias `sim = "run --release --target aarch64-apple-darwin --"`), `build.rs` (copies `patch.ld` to `OUT_DIR` and adds `-Tpatch.ld` for thumb targets), `patch.ld` (header at 0x80000000, `.patch_image` = text + rodata + data, `.patch_bss` NOLOAD, `patch_image_size` / `patch_bss_size` symbols, unwind tables discarded), `Cargo.toml` (package `super_pedal`, `[[bin]] super_pedal`, release `opt-level = 3`, `lto = "fat"`, `codegen-units = 1`, `panic = "abort"`, `debug = true`), `.gitignore` (`/target`, `.DS_Store`).
- **Files.** `src/main.rs` (`mod pedalkit; mod pedals; mod presets; mod rack; mod selector; mod super_pedal;` then `endless_patch!(kit = crate::pedalkit, pedal = crate::super_pedal::SuperPedal, memory = working);` and the host `main`), `src/pedals/` (the vendored pedals, `mod.rs` declaring each), `src/rack.rs`, `src/selector.rs`, `src/super_pedal.rs`, `src/presets.rs`, `src/prompts/*.ulaw`, `src/host/{mod.rs,score.rs}`, `sync.sh`, `make-prompts.sh`, `build-endl.sh` (`exec src/pedalkit/tools/build-endl.sh super_pedal superpedal "$@"`).
- **The knob order** (`rack.rs`, the `rack!` macro, one line per pedal `module => "Spoken name"`): position 0 "No pedal", then gojira "Gojira", harmonics "Harmonics", iron_butterfly "Iron Butterfly", jesus_mary_chain "Jesus and Mary Chain", led_zeppelin "Led Zeppelin", mirrorball "Mirrorball", nirvana "Nirvana", sabbath "Sabbath", sleep "Sleep", sound_garden "Soundgarden", surf "Surf" (alphabetical by repo name): 12 positions. The macro generates `POSITIONS`, `NAMES`, `PROMPTS` (`include_bytes!("prompts/none.ulaw")` then `concat!("prompts/", stringify!(module), ".ulaw")`), `MAX_POOL` (the largest `Patch::POOL`; a `const` assert in `super_pedal.rs` checks it fits `WORKING_BUFFER_SIZE`), and `struct Rack` holding every pedal at rest (`Patch::NEW`) with `get(pos) -> Option<&mut dyn Slot>` (0 → None) and `get_ref`. `Slot` is an object-safe wrapper implemented for every `P: Pedal`: `restart(pool)` (`*self = P::NEW; self.init(pool)`), `default_knob(k)`, `set_knob`, `press`, `hold`, `tick`, `led`, `block`. Adding a pedal: vendor it (`sync.sh` line + `pedals/mod.rs`), one `rack!` line, one `make-prompts.sh` line, one `TRIM_DB` entry.
- **The left knob** (`selector.rs`): its 0..1 travel split into `POSITIONS` equal zones (`zone = min(floor(v·n), n-1)`; with 12 positions on a 360° knob, every 30°). A zone change only counts once the knob is `HYSTERESIS = 0.01` of the travel past the boundary (or at either end), so a knob resting on a boundary can't flicker. Default 0.0 = "No pedal".
- **Announcements.** Every zone change (re)starts that position's spoken name immediately, through pedalkit's `voice::Announcer` (16 kHz mu-law, linear interpolation to 48 kHz, 7 kHz one-pole low-pass). Level `VOICE_LEVEL = 0.36`. The music ducks to `1 - 0.5·duck` under it (duck envelope 30 ms). Knob values the firmware sets before the first audio block are applied silently (the `live` flag, set in the first `block()`), so the setup isn't announced. The prompts are made by `make-prompts.sh` with `src/pedalkit/tools/make-prompts.sh src/prompts none="No pedal" gojira=Gojira ...` (macOS `say -v Samantha`, 16 kHz 16-bit, silence trimmed to 20 ms before / 50 ms after with threshold 300, normalised to −1 dBFS, G.711 mu-law). They are committed, so building needs no Mac. Sizes: 0.43–1.34 s, 138.6 KB for all 12, which fits at full quality. If a future set doesn't fit, use `RATE=` (faster speech) or a lower prompt sample rate before cutting anything else.
- **The other controls.** The mid knob is the selected pedal's knob 0 and the right knob its knob 1 (`PARAMS`: "Pedal" 0.0, "Ctrl 1" 0.6, "Ctrl 2" 0.5; the values are absolute: the knob's position applies to whichever pedal is selected). The selected pedal's knob 2 (Level on most) stays at its default. The footswitch press and hold go to the selected pedal while it's playing. The LED is the selected pedal's own; dim white for "No pedal". The runner shows red if the working buffer is missing.
- **Loudness.** Each position's output is multiplied by `TRIM_DB[pos]` (dB) so every pedal plays at `TARGET_DB = −18 dB` RMS on the calibration phrase at its own default knob settings: `[0.0, −3.8, 1.4, −7.5, −3.7, −5.0, −3.4, −5.8, 0.0, −3.5, −5.6, 1.2]` (order of `NAMES`; "No pedal" is the dry guitar, untouched). `CALIBRATE=1 cargo sim` prints the measured levels and a suggested table. The amp sets the volume. The output then goes through `soft_limit(x, 0.95)`.
- **Changing pedal** (`super_pedal.rs`, a three-phase machine run in `block()`, once per audio block):
  - **Playing.** When the target differs from the active position, go to Fading (fade target 0; `Smooth`, `FADE_S = 4 ms`).
  - **Fading.** If the knob comes back to the active position, fade back in. Once the fade is below 1e-3 (and the working buffer is attached, unless the target is "No pedal"): the target becomes active; `trim = db(TRIM_DB)`; `pool.reset()`; `restart` the pedal (`Patch::NEW` then `init`, taking its delay memory from the pool); set its knob 2 to its default and knobs 0/1 from the mid/right knobs; go to Clearing.
  - **Clearing.** Zero `CLEAR_PER_BLOCK = 16384` floats of the pool per block (output silent), then Playing with the fade target 1.
  - Only the active pedal runs (its `tick` per sample, its `block` per block while Playing). "No pedal" outputs the left input to both outputs.
- **Memory.** The pedals' delay memory is the firmware's 2.4M-float working buffer (`attach`), one `Pool` reused by whichever pedal is active (the largest takes ~83K floats). The patch's own `POOL` is 0. Measured build: 356,864-byte `.endl`, 16 bytes of `.bss`: 356,880 of the 524,288 bytes of patch RAM. Code and pedal state are ~98 KB, the 12 name prompts 139 KB, and harmonics' own four mode prompts 120 KB. There's room for roughly nine more pedals at ~18 KB each (code plus name).
- **Demo** (`cargo sim`, `src/host/`). For each of the 12 positions in order: set the left knob to the middle of its zone, wait `SETTLE = 1.8 s`, then play the same original phrase in E at 100 bpm (E5, G5, A5 power chords, two palm-muted E2 chugs, G3 B3 D4 eighths, a D4 bent +200 cents with vibrato, an open E chord), 7 s per position. The working buffer passed is the full 2.4M floats. It prints, per position, whether it was selected and settled by `SETTLE`, its level after the change, and its trim. It fails if a position wasn't selected in time, or on NaN or full-scale output. Writes `target/render/superpedal_demo.wav` (~85 s).
- **`sync.sh`** (POSIX sh; the `PEDALS` list of `repo:module` lines, alphabetical). `./sync.sh kit` copies `src/pedalkit` into every `../<repo>/src/pedalkit`; `./sync.sh pedals` copies every `../<repo>/src/<module>/` into `src/pedals/<module>/`; `./sync.sh check` (the default) reports any copy that differs and exits 1. Edit pedalkit here and the pedals in their own repos, then sync.

### Implementation decisions: pedalkit (the master copy, `src/pedalkit/`)

Reusable, pedal-agnostic building blocks. Modules refer to each other only through `super::` paths, so the directory can be lifted into its own crate. `#![allow(dead_code)]`, since each patch uses only part of it. Every file starts with a doc comment saying what it is.

- `abi.rs`: the FxPatchSDK `PatchABI.h` (ABI 0x000B) mirrored in Rust: `PATCH_MAGIC` 'PTCH', `PatchEnv`, the `PatchHeader` `#[repr(C)]` struct (magic, abi_version, flags, 13 entry points, image_size/bss_begin/bss_size as symbol addresses, 16 reserved words), `PARAM_COUNT = 3`, `ACTION_FOOTSWITCH_PRESS = 0`, `ACTION_FOOTSWITCH_HOLD = 1`, `WORKING_BUFFER_SIZE = 2_400_000`, `Color` in the SDK's order (DimWhite, DarkRed, DarkLime, DarkCobalt, LightYellow, DimBlue, Beige, DimCyan, Magenta, LightBlue, PastelGreen, DimYellow, Blue, LightGreen, Red, DimGreen).
- `dsp.rs`: f32 only (the FPU is single precision; `-fp64` keeps LLVM from emitting f64).
  - Maths: `SR = 48000`; `floor`; `sin` (|err| < 1e-6) and `cos`; `exp2` (degree-6 polynomial, 2e-5) and `exp`; `exp2_hq` / `exp_hq` (round-to-nearest reduction, degree 7, < 1e-7: for coefficients near 1 in the blocks ported from C++); `log2` (atanh series); `sqrt` (bit trick + 3 Newton steps); `powf` (0 for x ≤ 0); `db`; Padé `tanh` clamped to ±3; `coef(tau) = 1 - e^(-1/(tau·SR))`.
  - Filters: `OnePole` low-pass (`set` at 48 kHz, `set_at(fc, sr)` via `exp_hq`, `reset`); `OnePoleHp` (`y = a(y1 + x - x1)`, `a = e^(-2πfc/sr)`); `Biquad` (RBJ, transposed DF-II; `lowpass`/`highpass`/`bandpass`/`peak` at 48 kHz, `lowpass_at`/`highpass_at`/`peak_at`/`low_shelf_at`/`high_shelf_at` at any rate, `reset`).
  - `Delay<N>`: legacy, unused.
- `global.rs`: `Global<T>`, an `UnsafeCell` static with `get()` (the firmware calls every entry point from one thread).
- `pool.rs`: `Pool` (pointer + capacity; `take(n) -> Option<*mut f32>`, flagging an overflow; `used`, `reset`, `clear(from, to)`). On overflow a buffer falls back to a 4-float scratch: harmless garbage, and the runner shows red. `Line` (power-of-two delay line from the pool: `push`, `read(d)` linearly interpolated with d = 0 the newest and d clamped to len−2, `at(i)`, `clear`). `Ring` (any length, stepped once per sample: `get`, `set`, `step`, `slice`, `slot`).
- `pedal.rs`:
  - `Param { name, default }`.
  - `trait Pedal { const NEW; const PARAMS: [Param; 3]; const POOL: usize; fn init(&mut self, &mut Pool); fn set_knob(idx, v); fn press(); fn hold(); fn tick(l, r) -> (l, r); fn led() -> Color; fn attach(ptr, len) {} ; fn block() {} }`.
  - `Memory::{Static(ptr, len), Working}`.
  - `Runner<P>`. `init`: makes the pool, `pedal.init`, then zeroes the pool's used part, and sets an error on overflow. `set_buffer`: a null buffer is an error, otherwise `attach`. `update`: calls `block`, then `tick` per sample, only once ready. `set_param`: knobs 0..3, clamped to 0..1. `action`: press / hold. `led`: red on error. Also `param(idx)`, `pool_used`, `pedal()`.
  - `write_c_str`.
- `endless.rs`: `endless_patch!(kit = <path>, pedal = <path>[, memory = working])` generates `pub mod entry`.
  - The static `RUNNER`; for static memory, a `.bss` array of `P::POOL` floats.
  - The 13 `extern "C"` entry points: `patch_init` checks the env and ABI; `update_buffers`; `set_buffer`; `get_buffer_size`; `get_param_min/max/default`; `is_param_enabled` (source 0 only); `get_param_name` from `PARAMS`; `get_param_unit` (empty); `set_param`; `special_action`; `get_state_idx`.
  - The `#[unsafe(link_section = ".patch_header")]` `patch_header` and the panic handler (pedal builds only).
  - On the host: `ENTRY`, a `host::Entry` table of those functions, and `pedal()`.
- `helpers.rs`:
  - `Smooth`: a value gliding to a target, `v += (t - v)·c`, with `new`, `time(tau)`, `set`, `on(bool)`, `snap`, `value`, `tick`.
  - `Peak` (f, q, dB; `apply`); `Clip2x` (2x oversampled clipper: `0.5·(f(0.5·(u + prev)) + f(u))`); `Phase` (an accumulator wrapping once at 1).
  - `limit(x) = tanh(x)·0.98`; `hard(u)` (cubic, flat beyond ±1.5); `biased(u, b) = tanh(u + b) - tanh(b)`; `soft_limit(x, knee)` (`knee + (1-knee)·o/(1+o)` above the knee).
- `env.rs`: `Follower` (`env += (a - env)·(attack or release)`, times via `coef`), `Onset` (a slow copy of a fast envelope; `hit(env, ratio, min)`), `ExpEnvelope` (the C++ form: `c = e^(-1/(ms·fs))` via `exp_hq`, `env = c·env + (1-c)·|x|`).
- `gate.rs`: `Gate`. A `Follower` (attack/release), hysteresis (open above `open`, close below `close`, each scaled by `scale` in `process_with`), and the gain glides to 1 (`fade_in`) or to 0 (`fade_out`, or a given coefficient). `GateSettings { open, close, attack, release, fade_in, fade_out }`.
- `clean.rs`: `CleanAmp`: high-pass (Q 0.707), then a peak compressor (`a = |x|·drive`, target `0.5/a` above 0.5, `comp += (target - comp)·(attack if target < comp else release)`), then `tanh(x·drive·comp)·0.7`. `CleanSettings { hp_hz, drive, attack: Attack::{PerSample(c), Time(s)}, release }`.
- `eq.rs`: `Eq::{Hp(f,q), Lp(f,q), Peak(f,q,dB), Bp(f,q)}` and `EqChain<N>` (N biquads in series; `init(&[Eq; N])`, `reset`, `process`). Every cab and EQ chain.
- `amp/`: a valve head, `Amp` = `Preamp` (input HP, trim, biased triode via `Clip2x`, DC HP, interstage LP, second stage `tanh` via `Clip2x`) → `ToneStack` (bass/mid/upper `Peak`s, then `lo + (min + span·tone)·(y - lo)` above a one-pole split) → `PowerAmp` (sag `Follower`, `u = y·drive/(1 + sag·env)`, biased clip via `Clip2x`, resonance `Peak`, × out). Set by `Voicing { hp_in_hz, trim_db, bias, dc_hz, inter_lp_hz, stage2_db, bass, mid, upper, treble_hz, treble_min, treble_span, power_db, power_bias, sag, sag_attack, sag_release, reso, out }`.
- `muff.rs`: `Muff`, a Big Muff-style fuzz (HP, `tanh(gain·x)`, LP1, `tanh(stage2·y)`, LP2, tone blend `(lo_mix·LP + hi_mix·HP)·out`), crossfaded in by a `Smooth`. `MuffSettings { hp_hz, gain_db, lp1_hz, stage2, lp2_hz, tone_lo_hz, tone_lo_mix, tone_hi_hz, tone_hi_mix, out, fade }`.
- `wah.rs`: `Wah`, `x + amount·(db(boost) - 1)·BP(x)`, faded in. Parked (`init` at `park_hz`) or swept with `set_freq` / `set_position(0..1)` (exponential, heel to toe). `WahSettings { park_hz, heel_hz, toe_hz, q, boost_db, fade }`.
- `reverb.rs`: `Reverb`, Freeverb-style: up to 8 low-pass-feedback combs (`filt = o + (filt - o)·damp; buf = x + filt·fb`) summed into up to 4 Schroeder allpasses (feedback 0.5) per side, the right side spread. Pool-backed and exactly sized. `process(x, fb)`. `ReverbSettings { combs, allpasses, spread, damp, in_gain, out_gain, predelay: Option<f32> (2048-sample line) }`; `FREEVERB_COMBS = [1214, 1293, 1389, 1475, 1547, 1622, 1694, 1759]`, `FREEVERB_ALLPASSES = [605, 480, 371, 245]`.
- `feedback.rs`: `Feedback`, an amp-feedback loop. A 512-sample `Line`; `drive(on)` ramps up (`bloom`) or down (`die`); `read(norm) = line.read(delay)·ramp·gain/norm`; `send(y)` band-passes and pushes; `tune(hz)`. `FeedbackSettings { delay, freq, q, gain, bloom, die }`.
- `voice.rs`: `ulaw(byte)`, and `Announcer::new(&prompts)` with `init(duck_s)`, `say(i)`, `speak()` and `duck_step()` (see Announcements above).
- `guitar.rs` (host only): the modelled electric guitar, as in `../sleep` and `../ledZeppelin`: an extended Karplus-Strong string per note (fractional delay by Lagrange interpolation, exact tuning), two polarizations, a pick excitation with position comb and click, a bridge humbucker comb and 4.3 kHz resonance; `Note` (`new`, `vel`, `pm`, `t60`, `vib`, `bend`, `slide`) and `Player` (`play(notes, strum, ring)`, `release_all`, `tick`, human velocity and timing).
- `host/` (host only):
  - `Entry`; `Ev::{Play(notes, strum, ring), Release, Press, Hold, Knob(i, v), Custom(id, v)}`; `Score`.
  - `render` / `render_with(hook per block)` / `render_extra(&mut dyn Extra)`. Each calls `patch_init`, then `set_buffer` (`Options.working` floats), then every knob at its default. It plays events at block starts, feeds `guitar·input_trim` (plus `Extra::tick` when `has_source`) into the left channel and 0 into the right, in 128-sample blocks.
  - `Render { l, r, input, sections, env, work }`, with `section(prefix)`.
  - `finish` (stats, LED, WAV, exit 1 on NaN/full scale); `stats::{report, rms, to_db}`; `wav::write_wav` (stereo float).
  - `PEDAL_DUMP=<dir>` writes `input.f32` and `events.txt` (`<sample> P|H|K i v`), to replay through another implementation.
- `tools/`:
  - `build-endl.sh <bin> <name> [--deploy]`: `cargo build --release`; `llvm-objcopy -O binary` to `target/endless/<name>.endl`; f64 check of instructions inside function symbols only (`llvm-objdump -t` ranges, since rodata such as prompts is otherwise misread as code); header + image + bss ≤ 524288 (`llvm-size -A`); `check_endl.py`; `--deploy` writes `upload.tmp`, syncs, then renames on `/Volumes/ENDLESS` (or `$ENDLESS_VOLUME`).
  - `check_endl.py`: validates magic, ABI, flags, the entry points inside the image with the Thumb bit, image size, bss placement and the 512 KB fit; a large bss is only a note.
  - `make-prompts.sh <dir> file=text ...` (`VOICE`, `RATE`).

6. **Keep the user's controls of each original pedal unchanged; only superPedal remaps the knobs** (see requirement 3's verification).
